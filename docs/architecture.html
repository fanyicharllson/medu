Compiler Construction project · architecture

Medu: a compiler for Medumba

Medu reads Mə̀dʉ̂mbɑ̀ (the language of Bangangté), checks it for syntax errors, and translates it into English. Next step: a dual compiler that also understands Bafut.

Project lead & architect: Fanyi Charllson Dictionary: 2,249 Medumba entries Python · open source (GPL-3.0)
How you use it

Like Python, but you write Medumba

Write Medumba in a text file, save it, and run medu in a terminal. Medu checks the file and prints the result. Typing medu on its own opens an interactive prompt.

Mode 1 · programs (.med) 
lɛn = "Emperor"
<print>(lɛn)        # keyword chosen with a speaker

> medu run hello.med
English: print(name)
Output:  Emperor
Mode 2 · sentences (.mdt) 
mə nɛn zi.

> medu translate story.mdt
I am sleeping.

medu> mə zii
error: unknown word 'zii' (line 1, col 4)
  did you mean 'zi' (sleep)?
The architecture

Six stations, one job each

Text goes in on the left. Each station does one thing and passes its result on. Stations ① and ② are shared by both modes. Any station can stop the line and report an error.

Typing Medumba

No special keyboard needed

Keyboards don't have ə, ɛ, ʉ, ɑ, ŋ, ʼ or tone marks, so Medu accepts plain letters and works out the real word. Of the 2,023 distinct words in the dictionary, about two-thirds still have exactly one match when typed this way; for the rest, the grammar picks the one that fits.

Type plain letters 
medu> me nen zi
I am sleeping.
  (read as: mə nɛ̌n zi)

> medu fmt story.mdt
rewrote 1 line: me nen zi → mə nɛ̌n zi

Proposal

Medu as a dual compiler: Medumba and Bafut

Station ⑤ writes meaning in no particular language, so a second language only needs its own front stations and dictionary. The meaning and English stations are reused as they are. Medu picks the right front from the file extension or detects the language by itself.

Little extra codeBafut reuses ⑤ and ⑥; only its front and dictionary are new.
Translates between themMedumba ↔ Bafut through the shared meaning, not only into English.
Data neededPermission for SIL's Bafut dictionary (6,152 entries), requested by email.
